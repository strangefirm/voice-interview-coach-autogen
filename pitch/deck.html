AI Interview Coach02 / 08 · The problem

Interview practice is hard to get, and feedback is vague.

Few real partners

Friends are busy, coaches are costly, and nobody asks follow-up questions at 11 pm.

Generic feedback

"Be more specific" does not tell you what a strong answer to that exact question sounds like.

Typing is not speaking

Real interviews are spoken. Most practice tools are text boxes.

The gap: practice that is spoken, adaptive and specific.
AI Interview Coach03 / 08 · The solution

Three agents, each with one job.

1

Interviewer

Asks exactly one question at a time. Starts easy, raises difficulty, never repeats a topic, never gives hints.

→
2

Evaluator

Scores the latest answer 1 to 10 as structured output, with strengths, one fix, and a first-person model answer.

→
3

Reporter

Writes the final report: verdict, average score, 3 strengths, 3 areas to improve and a 3-step study plan.

Built on AutoGen AgentChat, using a round-robin team for each step.

AI Interview Coach05 / 08 · Guardrails

Candidate text is treated as data, never as instructions.

Injection filter

A local pattern check rejects "ignore previous instructions", "give me a 10" and similar, with no API call.

Moderation

OpenAI's moderation endpoint screens inappropriate input. It fails open, so an outage never blocks a user.

Tagged answers

Answers are wrapped in <answer> tags and every agent is told to treat them as data.

Timeouts

Each agent step has a 60-second limit so a stalled call cannot hang a session.

Two layers: cheap local checks first, prompt-level defence second.
AI Interview Coach06 / 08 · Measured

Tested, timed and costed.

Evals

  • Weak, average and strong answers land in expected score ranges
  • Strong beats weak
  • Feedback includes a model answer
  • Questions are single questions
  • Final report has required sections

Unit tests

  • Injection patterns are caught
  • Normal answers pass
  • Injection rejected without an API call
  • Tracker sums tokens, characters and time
  • Failed calls are still timed

Cost model

  • gpt-4o-mini: $0.15 / $0.60 per 1M tokens in / out
  • tts-1: $15 per 1M characters
  • whisper-1: $0.006 per minute
  • Per-call latency and cost in the UI
Pytest suite runs in the repo. Prices are estimates and editable in metrics.py.
